# Reports

Write-ups built from the benchmark data. `MODELS.md` at the repo root is the working
record of every run, every failure and every correction. These are the readable
summaries, and they carry the confidence levels a table of numbers does not.

| Report | Covers |
|---|---|
| [`48gb-question.md`](48gb-question.md) | Seven models against the weather-cli benchmark. Which fit a 48 GB Pro, which levers moved the numbers, and how far the results can be trusted |
| [`nav-pilot-path.md`](nav-pilot-path.md) | Whether to bundle local inference into nav-pilot as an alpha command. Seat economics, break-even, and what to check before building |
| [`alpha-model-decision.md`](alpha-model-decision.md) | Which model to run in the nav-pilot alpha, the evidence for it, what was rejected, and the three things the alpha must handle |
| [`status-2026-08-27.md`](status-2026-08-27.md) | Status update for a wider audience. Where the work stands, what changed in our thinking, and what we do not know yet |

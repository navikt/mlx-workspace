# Reports

Published write-ups of the benchmark results. Each is a self-contained HTML page
with no external assets beyond Google Fonts, so it renders from disk as-is.

`MODELS.md` at the repo root is the working record — every run, every failure,
every correction. These pages are the readable summary built from it, and they
carry the confidence levels that a table of numbers does not.

| Report | Covers | Published |
|---|---|---|
| [`48gb-question.html`](48gb-question.html) | Seven models against the weather-cli benchmark; which fit a 48 GB Pro, which levers moved the numbers, and how far the results can be trusted | https://claude.ai/code/artifact/6807ccc4-e846-4371-a77c-dfb5b9a066c1 |

## Updating a report

The HTML in this directory is the source. Edit it here, then republish to the
same URL so the link people already have keeps working — publishing without the
existing URL creates a second artifact instead of updating the first.

# `nav-pilot alpha decide`: option order and consistency

Layout: `default` is what nav-pilot ships (evidence, then question, options, instruction); `options-first` is question and options, then evidence, then the same instruction. Consistency: `swap` lists the options in reverse order; `negate` asks the negated question with the expected answer flipped. Cells are correct/n = accuracy [95% Wilson]; an errored call counts as wrong. Paired p is the exact two-sided McNemar test on the discordant cases (b = only default right, c = only options-first right).
